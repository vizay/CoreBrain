# OpenAPI

> **Summary**: OpenAPI (formerly Swagger) is the open standard specification for describing RESTful APIs; FastAPI generates a compliant schema automatically from type-annotated route definitions.

## Core Concept

OpenAPI is an open specification standard for machine-readable REST API definitions. A compliant OpenAPI schema describes every endpoint, its parameters, request bodies, response types, and authentication methods in a structured JSON/YAML format. Tools can consume this schema to generate interactive documentation UIs, client SDKs, and server stubs automatically.

[[FastAPI]] is described in the source as "based on (and fully compatible with) the open standards for APIs: OpenAPI (previously known as Swagger) and JSON Schema."

## Key Points

- **Formerly Swagger**: The OpenAPI Specification was originally called the Swagger Specification; the two names are often used interchangeably for the format (Swagger UI is the specific documentation tool).
- **Auto-generated by FastAPI**: [[FastAPI]] generates a fully compliant OpenAPI schema automatically — no manual spec writing required. The schema is derived from Python type hints and route decorators.
- **Two interactive UIs** are served by FastAPI out of the box:
  - **Swagger UI** at `/docs` — interactive "Try it out" interface
  - **ReDoc** at `/redoc` — alternative read-optimized documentation
- **JSON Schema compatible**: OpenAPI builds on JSON Schema for describing data types; [[Pydantic]] models map directly to JSON Schema objects.
- **Client code generation**: The OpenAPI schema can drive automatic client SDK generation for many languages.

## Role in FastAPI

OpenAPI is the documentation and interoperability standard that [[FastAPI]] is built to emit. Every route, model, and parameter defined in a FastAPI app is automatically reflected in the `/openapi.json` schema endpoint.
